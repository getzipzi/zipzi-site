# Zipzi 2D website

Zipzi 2D 的简体中文产品官网。独立静态项目，包含深色蓝紫视觉、真实编辑器开发截图、创作工作流和 Python SDK 介绍。

Zipzi 2D 产品仍在开发中，尚未正式发布。网页不提供未经确认的正式下载、平台支持或用户案例。

## 本地开发

需要 Node.js 18+、Python 3。无需安装 npm 依赖。

```sh
npm run lint
npm run build
npm test
npm run preview
```

预览地址为 `http://127.0.0.1:4173`。构建生成 `dist/` 与本地资源清单 `qa/build-manifest.json`。

## 项目结构

- `src/index.html`：页面结构、中文文案、开发状态与 FAQ。
- `src/assets/site.css`：响应式样式。
- `src/assets/site.js`：移动导航及键盘交互。
- `src/assets/editor-modeling.png`：真实编辑器内置几何测试场景截图，保持原始像素。
- `scripts/build.mjs`：零依赖静态构建，为资源添加内容哈希。
- `scripts/check.mjs`：检查锚点、唯一 ID、文案披露和远程依赖。
- `scripts/site.test.mjs`：检查生成资源、哈希、清单及文件大小预算。

## 素材与产品信息

编辑器截图来自 Zipzi 2D 原生应用的网格编辑验收场景，仅使用内置几何测试文档，不包含第三方角色模型。页面明确标注开发版本，截图保留旧 `.kasane` 文件名。

产品与 SDK 文案基于项目文档；Python 代码是网格创建示例节选，并非网页运行结果。原生编辑器面向 macOS / Metal；SDK 和文件格式仍在演进。

官网借鉴用户选定参考的布局节奏，未复制第三方品牌、图片或文案。所有运行资产在本地提供，没有远程字体、分析脚本或运行时服务依赖。

## 发布

`dist/` 可作为独立静态站部署。实际服务器可能还承载其他网站或管理入口，部署前应使用该环境自己的备份、路由与回滚流程，不能直接清空目标目录。

本仓库仅包含官网源码和本地构建检查。服务器配置、认证信息、备份、运行日志、发布包和部署脚本由 `.gitignore` 排除，不随源码提交。页面中的备案信息对应当前已备案站点，切换域名前须核实新域名的备案与 HTTPS 条件。
