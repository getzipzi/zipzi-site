Zipzi 2D 与 Kasane 2D 是什么关系？+

Zipzi 2D 是原 Kasane 2D 项目的新名称，延续二维建模、动画与可编程工具的开发方向。开发截图中仍可能出现旧格式名称。

它只用于角色动画吗？+

不局限于角色或特定画风。项目面向更广泛的二维建模与动画工作流，既关注创作者的编辑体验，也为开发者提供 SDK。
